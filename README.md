# 🎵 ربات پیشرفته دانلود آهنگ (فارسی و انگلیسی)

این یک ربات تلگرام حرفه‌ای و هوشمند برای جستجو و دانلود آهنگ است که به زبان پایتون توسعه یافته و مجهز به دیتابیس داخلی SQLite و پنل مدیریت پیشرفته می‌باشد.

## ✨ قابلیت‌های اصلی ربات:
* 🌐 **پشتیبانی دو زبانه:** منوی کامل به دو زبان فارسی و انگلیسی (تعیین شده توسط کاربر).
* 📢 **عضویت اجباری:** قفل هوشمند کانال تلگرام برای جذب عضو جدید (تا کاربر عضو نشود، ربات خدمات نمی‌دهد).
* 🔙 **دکمه برگشت:** کیبورد شیک و منظم با دسترسی راحت به منوی اصلی.
* 🛠 **پنل مدیریت پیشرفته (`/admin`):** مخصوص رئیس ربات جهت مشاهده آمار و مدیریت.
* 📊 **سیستم آمار دقیق کاربران:** ذخیره دائمی مشخصات کاربران در دیتابیس SQLite.
* 📢 **ارسال پیام همگانی:** قابلیت ارسال بنر تبلیغاتی یا متن به تمام اعضای ربات به صورت یکجا از طریق پنل مدیریت.

## 📦 نیازمندی‌های سیستم (Dependencies)
* Python 3.x
* pyTelegramBotAPI
* SQLite3

## 🛠 راهنمای تنظیم متغیرهای محیطی (Environment Variables)
برای اجرای ربات روی سرورهایی مثل Render، متغیرهای زیر را در بخش تنظیمات سرور وارد کنید:
* `API_TOKEN`: توکن دریافت شده از BotFather
* `CHANNEL_ID`: آیدی کانال شما همراه با @
* `CHANNEL_LINK`: لینک کامل دعوت کانال شما
* `ADMIN_ID`: آیدی عددی حساب تلگرام شما
